## 阶段 1：试用服务器部署

**目标**：游戏跑在云端，朋友能联机玩

### 1.1 申请腾讯云试用服务器

1. 打开腾讯云活动页面，找到试用入口
2. 申请 **轻量应用服务器**：2核2G / 50GB SSD / 300GB流量 / 4Mbps
3. 系统选择 **Ubuntu 22.04**
4. 申请成功后会得到：**IP 地址 + 登录密码**

### 1.2 登录服务器

打开 Windows 命令提示符（cmd）或 PowerShell：

```bash
ssh root@你的IP地址
```

第一次连接问是否信任，输入 `yes`，然后输入密码。

### 1.3 服务器初始化

```bash
# 更新系统
apt update && apt upgrade -y

# 安装 Docker
curl -fsSL https://get.docker.com | sh

# 验证
docker --version
```

### 1.4 部署游戏

因为还没有 GitHub 仓库，先用 scp 把代码传到服务器：

**在你的 Windows 电脑上执行**（不是服务器上）：

```bash
# 压缩项目（排除 node_modules 和 dist）
# 在项目根目录执行：
powershell Compress-Archive -Path "C:\Users\zhm\Desktop\TOD\projects\monopoly" -DestinationPath "C:\Users\zhm\Desktop\monopoly.zip"

# 上传到服务器
scp C:\Users\zhm\Desktop\monopoly.zip root@你的IP:/root/
```

**在服务器上执行**：

```bash
# 解压
apt install -y unzip
cd /root
unzip monopoly.zip -d /opt/monopoly

# 进入项目目录
cd /opt/monopoly

# 构建 Docker 镜像并启动容器
docker compose up -d --build
```

> 如果服务器上 docker compose 命令不可用，改用：`docker-compose up -d --build`

### 1.5 验证运行状态

```bash
# 查看容器是否在运行
docker compose ps
# 应看到 monopoly-game 状态为 Up

# 查看启动日志
docker compose logs -f
# 应看到：🎮 大富翁——重庆之旅服务器: http://localhost:8080

# 健康检查
curl http://localhost:8080/health
# 应返回：{"ok":true,"rooms":0}
```

### 1.6 配置防火墙

```bash
# 服务器防火墙
ufw allow 22/tcp     # SSH
ufw allow 8080/tcp   # 游戏服务
ufw enable
```

**腾讯云控制台也要放行 8080**：
- 登录腾讯云 → 轻量应用服务器 → 你的实例 → 防火墙 → 添加规则
- 端口：8080，来源：0.0.0.0/0

### 1.7 测试联机

- 浏览器打开 `http://你的IP:8080`，应该能看到游戏首页
- 点击"联机模式" → 创建房间
- 让朋友用他的浏览器打开 `http://你的IP:8080` → 加入房间（输入房间号）
- 双方准备 → 开始游戏

### 1.8 常见问题排查

**问题：浏览器打不开 `http://IP:8080`**

```bash
# 检查容器是否运行
docker compose ps

# 检查日志
docker compose logs

# 检查端口监听
ss -tlnp | grep 8080

# 检查腾讯云控制台安全组是否放行 8080
```

**问题：朋友连不上房间**

```bash
# 检查 Socket.IO 连接
docker compose logs | grep -i "connect\|error\|disconnect"

# 检查服务器时间
date
```

**问题：构建失败**

```bash
# 查看详细构建日志
docker compose build --no-cache

# 检查 Docker 是否正常运行
docker info
```

### 1.9 后续代码更新

当你修改了本地代码，重新部署：

```bash
# Windows 上重新打包上传
powershell Compress-Archive -Path "C:\Users\zhm\Desktop\TOD\projects\monopoly" -DestinationPath "C:\Users\zhm\Desktop\monopoly.zip" -Force
scp C:\Users\zhm\Desktop\monopoly.zip root@你的IP:/root/

# 服务器上
cd /opt/monopoly
docker compose down
rm -rf /opt/monopoly
unzip /root/monopoly.zip -d /opt/
cd /opt/monopoly
docker compose up -d --build
```

## 阶段 2：手机 App 套壳 + UI 适配

**目标**：手机能安装这个游戏，并且触屏好用

### 2.1 安装 Capacitor

在项目根目录执行（Windows）：

```bash
cd C:\Users\zhm\Desktop\TOD\projects\monopoly

# 安装核心包
npm install @capacitor/core @capacitor/cli

# 安装平台包
npm install @capacitor/ios @capacitor/android

# 初始化（替换成你的信息）
npx cap init "大富翁重庆之旅" com.yourname.monopoly --web-dir dist
```

### 2.2 配置 Capacitor

编辑生成的 `capacitor.config.json`：

```json
{
  "appId": "com.yourname.monopoly",
  "appName": "大富翁重庆之旅",
  "webDir": "dist",
  "server": {
    "androidScheme": "https"
  },
  "ios": {
    "contentInset": "automatic"
  },
  "android": {
    "allowMixedContent": true
  }
}
```

> `allowMixedContent: true` 允许 Android App 加载 HTTP 内容（因为你没有 HTTPS）

### 2.3 添加平台工程

```bash
npx cap add ios
npx cap add android
```

### 2.4 构建并同步

```bash
# 构建前端
npm run build

# 同步到原生工程
npx cap sync
```

### 2.5 打开原生 IDE

```bash
# iOS（需要 Mac + Xcode）
npx cap open ios

# Android（需要 Android Studio）
npx cap open android
```

### 2.6 真机运行

**iOS（Xcode）**：
1. 用 Xcode 打开 `ios/App/App.xcworkspace`
2. 连接 iPhone 或选择模拟器
3. 点 **Run**（▶）
4. 非 Apple 开发者账号：可用自己的 Apple ID 免费签名，7 天有效期，需每周重签

**Android（Android Studio）**：
1. 用 Android Studio 打开 `android/`
2. 连接手机（开启 USB 调试）
3. 点 **Run**（▶）
4. 不需要开发者账号

### 2.7 App 内连接服务器

App 里的 `src/net/socket.js` 需要连你的服务器：

```javascript
// 生产环境：连你的服务器 IP
const socket = io('http://你的服务器IP:8080', {
  transports: ['websocket', 'polling'],
  reconnection: true,
});
```
