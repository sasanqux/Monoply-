🎨 玩家配色方案 · 展示页

目标：玩家颜色和地图颜色（普通地产黑 / 景点绿 / 轻轨青 / 商圈紫 / 起点棕）彻底区分开 · 棋子沿用方案 C（名字首字 + 名牌）

⚠️ 当前玩家色里 黑（撞地产黑框）、绿（撞景点）、紫（撞商圈）、青（撞轻轨）——这四个必须换掉。
方案 A条纹玩家色

每个玩家一种条纹/图案（斜纹/竖纹/波点/方格），地图上的格子全是纯色，条纹一眼区分。棋盘格购买后也涂成对应条纹。

格子购买后 = 玩家条纹 我阿蓝 蓝阿绿 绿阿橙 橙阿紫
红白斜纹 / 蓝白斜纹 / 橙白竖纹 / 粉白横纹 / 紫白波点 / 青白斜纹 / 绿白方格 / 黑黄斜纹
方案 B新纯色板

换一套地图上没有的纯色（避开黑/绿/紫/青），风格干净。格子购买后涂纯色。

格子购买后 = 玩家纯色 我阿蓝 蓝阿绿 绿阿橙 橙阿紫
蓝 / 橙 / 粉 / 洋红 / 天蓝 / 玫红 / 靛蓝 / 琥珀 — 8 色尽量避开地图色
方案 C纯色 + 白环

新纯色板基础上，棋子圆盘加一圈白色粗描边——白环是"玩家专属"标记，地图格没有白环。

白环只在玩家棋子/格子上 我阿蓝 蓝阿绿 绿阿橙 橙阿紫
纯色 + 白环，干净又不撞地图色
